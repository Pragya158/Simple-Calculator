🧮 Simple Calculator

A simple, clean, and responsive calculator built using HTML, CSS, and JavaScript.

This calculator performs basic mathematical operations with an easy-to-use interface and a responsive layout.

✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- % Percentage
- 🔢 Decimal calculations
- 🔢 Double Zero ("00") button
- 🧹 Clear ("C") button
- ⌫ Delete ("DEL") button
- 🟰 Equal ("=") button
- ⌨️ Keyboard support
- 📱 Responsive design
- 🎨 Clean and user-friendly interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 Getting Started

Follow these steps to run the project locally:

1. Clone this repository:

   git clone https://github.com/Pragya158/Simple-Calculator

2. Open the project folder.

3. Open "index.html" in your browser.

4. Start using the calculator!

📖 How to Use

1. Enter numbers using the calculator buttons.
2. Select the required mathematical operator.
3. Enter the second number.
4. Press "=" to get the result.
5. Use "DEL" to remove the last entered character.
6. Use "C" to clear the display.
7. You can also use your keyboard for calculations.
